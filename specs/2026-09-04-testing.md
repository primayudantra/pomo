# Testing Strategy

Date: 2026-09-04
Parent: `2026-09-04-adhd-focus-overview.md`

The repo currently has **no tests**. This work introduces the first `_test.go`
files and a `make test` target. TDD applies to the pure-logic packages; the
OS-integration edges get thin seams and manual verification.

## 1. `make test`

```makefile
test:
	go test ./...
```

Add to `.PHONY`. CI is out of scope for v1 but the target must be green before
merge.

## 2. Unit tests (write these first, TDD)

### `internal/report`
- `Build` against an in-memory / temp-file SQLite seeded with known sessions +
  drift events. Assert every `Summary` field: planned/completed counts, focus vs
  planned seconds, drift totals, `DriftByApp` grouping + sort, `ByTag`, `Streak`
  (including a gap day breaking the streak), `BestHour` (and `nil` on no data).
- `ParseWindow` — `today`, `week`, `month`, `2026-W36`, `2026-09`, garbage.
- `RenderMarkdown` — golden file for a fixed `Summary` + recap and one with recap
  omitted.
- `Summary.JSON()` — stable key set (guards the `--json` contract).

### `internal/nudge`
- `State.Evaluate` table tests: no episode → no fire; episode but within
  `MinGap` → no fire; `Count == MaxPerSession` → no fire; level progression
  1→2→3→3; checkpoint `y` resets level+count; `snooze` pushes `LastAt`.
- Canned template selection per level, including the "no distract app" L2
  fallback.
- De-dup: `Nudger` returning a line already in `lastLines` → canned used.

### drift scoring (`internal/daemon` or wherever `tick` lives)
- Extract the scoring decision into a pure function:
  `score(signals Signals, state *scoreState, cfg) (drifting bool, reason string)`.
  Table tests: distract below/at/above `DistractGrace`; `fsStale` with
  foreground focus vs neutral vs distract; checkpoint `no` within penalty
  window; recovery closing an episode after `RecoverGrace`.
- Episode lifecycle: feed a sequence of ticks, assert the sequence of
  `OpenDriftEpisode` / `UpdateDriftEpisode` / `CloseDriftEpisode` calls against a
  fake DB.

### `internal/watch`
- `classify(app, cfg)` table tests: each default focus/distract app; browser +
  focus title hint → neutral; browser + plain title → distract; user override
  wins; unknown → neutral.
- `Watcher` is an interface — daemon tests inject a `fakeWatcher` returning a
  scripted sequence of `ForegroundApp`.

### `internal/ai`
- Provider transport tests against an `httptest.Server`:
  - anthropic non-stream: request has `x-api-key` + `anthropic-version`; response
    `.content[0].text` parsed.
  - openrouter non-stream: `Authorization: Bearer`; `.choices[0].message.content`.
  - stream: server emits scripted SSE; assert deltas delivered in order and
    `[DONE]` / `message_stop` terminates.
  - non-2xx and timeout → typed error; `Provider == ""` → `ErrNoProvider`
    without any HTTP call.
- `nudge` + `ai` integration: fake provider returns a line → used; fake errors →
  canned.

### `internal/ipc`
- `Serve` + two `Dial` clients; `Broadcast` reaches both; one client disconnects
  mid-stream → the other still receives; stale socket file is cleaned on
  `Serve`.
- Round-trip: client sends `checkpoint-answer`, server handler receives the
  decoded `Event`.

### `internal/pomoconfig`
- `Load` parses every new key; bad duration / bad enum falls back to default and
  does not error.
- CSV list keys append to (not replace) the built-in list.

### `internal/db`
- `ensureColumn` idempotent: run twice, no error, column present once.
- `OpenDriftEpisode` / `Update` / `Close` / `ListDriftEvents` round-trip on a
  temp DB.
- Existing methods still pass after the `repo_path` / `repo_branch` additions
  (add coverage for those two fields on `CreateSession` / `LastRunningSession`).
- WAL DSN: two `*sql.DB` handles on one temp file, concurrent small writes, no
  `database is locked` within the busy timeout.

## 3. Manual verification (documented in the PR)

Things not worth automating (OS-specific, GUI, timing):

- `pomo daemon start` installs and loads the launchd plist on macOS; `status`
  shows it up; `stop` unloads and removes it.
- Real drift: start a session, switch to Chrome for 4 min → OS notification
  fires, inline banner shows in the timer, `drift_events` row written, `/drift`
  shows it, `/review` totals include it.
- Checkpoint prompt appears mid-session; answering `y` suppresses the next nudge.
- macOS automation (TCC) prompt on first tab-title read; denying it → daemon
  keeps running, `pomo daemon status` reports `title tracking: degraded`, app
  classification still works.
- `/chat` streams token-by-token with a real key (both providers); no key →
  the "set ai.provider" placeholder.
- `pomo digest` writes a well-formed markdown file; Monday auto-write produces
  last week's file once.
- Kill the daemon mid-session → timer keeps working, no error, drift features
  silently stop.

## 4. Test helpers

- `internal/db/dbtest` — `NewTemp(t)` returns a `*DB` on a `t.TempDir()` file,
  auto-closed via `t.Cleanup`.
- `internal/report/reporttest` — `Seed(db, ...)` builders for sessions + drift
  events.
- `fakeWatcher`, `fakeNudger`, `fakeProvider`, `fakeIPC` live next to the code
  that consumes the interface (`_test.go`, unexported).
